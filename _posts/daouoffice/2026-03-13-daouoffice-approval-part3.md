---

이번 글에서는 결재 문서를 처음부터 끝까지 상신하는 과정을 단계별로 정리한다.

##  2. 양식 선택

---

결재 문서 작성은 양식(Form) 선택에서 시작한다. 양식에는 문서의 형식, 필드 구성, 결재선 고정 여부 등이 미리 정의되어 있다.

🧭 임직원 포털 > 전자결재 App > `[새 결재 진행]` 클릭

```
1. 양식 카테고리 목록에서 탐색
   - 카테고리 클릭 시 해당 양식 목록이 오른쪽에 표시됨
   - 양식 선택 시 오른쪽 하단에 상세 정보(설명, 결재선 구성 등) 미리 보기 가능

2. 양식 검색
   - 상단 검색창에 양식 제목 입력 → 검색 결과 클릭

3. [확인] 클릭 → 문서 작성 화면으로 이동
```

> 💡 양식에 따라 결재선, 공개여부, 보존연한이 미리 고정되어 있을 수 있다. 양식 상세 설명을 확인하고 선택하자.

### 📌 자주 쓰는 양식 관리

반복적으로 사용하는 양식은 '자주 쓰는 양식'으로 등록해 두면 홈에서 바로 접근할 수 있다.

```
[추가]
새 결재 진행 > 원하는 양식 선택 > 오른쪽 상단 [+ 자주 쓰는 양식으로 추가] 클릭

[순서 변경]
홈 화면 > 자주 쓰는 양식 목록 옆 ✏️ 클릭 > 드래그 앤 드롭으로 순서 조정 > ✔️ 저장

[삭제]
✏️ 클릭 > 삭제할 양식의 [X] 클릭 > ✔️ 저장
```

##  3. 문서 작성

---

양식을 선택하면 문서 작성 화면으로 이동한다.

### 📌 본문 작성

양식에 정의된 필드와 형식에 맞게 작성한다. 양식마다 입력 필드 구성이 다를 수 있다.

### 📌 파일 첨부

| 첨부 방식 | 설명 |
| --- | --- |
| 파일 첨부 | 내 컴퓨터에서 직접 파일 업로드 |
| 문서 검색 | 전자결재 문서함에 이미 완료된 결재문서를 연관 첨부 (결재 완료 문서만 가능) |

> 💡 관련 결재 문서를 첨부해 두면 수신자나 결재자가 이전 결재 내역을 바로 확인할 수 있다.

---

##  4. 문서정보 설정

---

본문 작성 후 화면 오른쪽 또는 하단의 `[문서정보]` 클릭하여 문서 메타 정보를 설정한다.

### 📌 문서정보 주요 항목

| 항목 | 설명 | 비고 |
| --- | --- | --- |
| 공개여부 | 전사 문서함 공개 여부 설정. 비공개 시 기안자·결재자·참조자·열람자만 조회 가능 | 양식에 따라 고정될 수 있음 |
| 보존연한 | 결재 완료 문서를 시스템에 보존하는 기간 | 양식에 따라 고정될 수 있음 |
| 긴급 문서 | 체크 시 결재자 문서 목록 최상단에 '긴급' 태그로 표시 | 급한 결재 요청 시 사용 |

> 💡 공개여부·보존연한·참조자·수신자 등은 양식 설정에 따라 수정이 불가능하거나 해당 항목 자체가 표시되지 않을 수 있다.

##  5. 결재선 설정

---

결재선 설정은 상신 전 마지막 단계이자 가장 중요한 단계다. 누가 결재하고, 누가 협조하고, 누가 문서를 받을지를 여기서 결정한다.

🧭 문서 작성 화면 > `[결재 정보]` 클릭 > 조직도 패널 열림

### 📌 결재선 구성 역할

| 역할 | 지정 단위 | 열람 시점 | 처리 내용 |
| --- | --- | --- | --- |
| 결재자 | 사용자 | 내 차례가 되면 | 승인 또는 반려 (핵심 결재) |
| 합의자 | 사용자 / 부서 | 합의 순서가 되면 | 합의 또는 반대 (타 부서 협조) |
| 수신자 | 사용자 / 부서 | 결재 완료 후 | 접수 또는 반송 (후속 업무) |
| 참조자 | 사용자 / 부서 | 진행 중 + 완료 후 | 열람 (진행 상황 공유) |
| 열람자 | 사용자만 | 결재 완료 후 | 열람 (완료 후 확인) |

**지정 방법:**
```
조직도 패널에서 지정하려는 직원을 드래그
→ 해당 역할 칸에 드롭
→ 순서 조정이 필요하면 위아래로 드래그
```

### 📌 결재선 순서와 방식

결재자가 여러 명일 경우 위에서 아래 순서대로 처리된다. 합의자 처리 방식(순차/병렬)은 별도로 설정한다.

**합의 방식 설정:**
```
결재 정보 창 > 합의자 추가 후
→ 합의 방식 선택: [순차합의] / [병렬합의]
```

- **순차합의**: 지정된 순서대로 한 명씩 합의 요청
- **병렬합의**: 모든 합의자에게 동시에 합의 요청, 순서 무관

### 📌 나의 결재선 저장 & 불러오기

자주 사용하는 결재선 조합을 개인 결재선으로 저장해두면 다음번에 빠르게 불러올 수 있다.

```
[저장]
결재 정보 창 > 결재선 지정 완료 후
→ 하단 [개인 결재선으로 저장] 클릭
→ 결재선 이름 입력 > [확인]

[불러오기]
결재 정보 창 > [나의 결재선] 탭 클릭
→ 저장된 결재선 목록 중 선택
→ 결재선 자동 적용
```

> 💡 자주 사용하는 결재선 조합(예: 팀장 → 본부장 → 인사팀 합의)을 저장해두면 반복 작업을 크게 줄일 수 있다.

### 📌 참조자 / 열람자 지정

참조자·열람자는 결재선의 별도 탭에서 지정한다.

```
결재 정보 창 > [참조자/열람자] 탭 클릭
→ 조직도에서 직원 드래그하여 추가
→ [확인]
```

자주 사용하는 참조자·열람자 조합은 **개인 그룹**으로 저장 가능하다.
```
참조자/열람자 지정 완료 후 하단 [개인 그룹으로 저장] > 이름 입력 > [확인]
이후 사용: [개인 그룹] 탭 > 저장된 그룹 선택
```

##  6. 결재 요청 (상신)

---

결재선 설정까지 완료되면 상신 준비가 끝난다.

```
문서 작성 화면 하단 또는 상단 > [결재 요청] 클릭
→ 첫 번째 결재자에게 결재 요청 알림 발송
→ 기안 문서함에 '진행 중' 상태로 표시
```

### 📌 임시저장

작성 중 저장이 필요하면 임시저장 후 나중에 이어서 작성할 수 있다.

```
[결재 요청] 대신 [임시저장] 클릭
→ 임시 저장함에 보관
→ 이후: 임시 저장함 > 해당 문서 클릭 > 이어서 작성 > [결재 요청]
```

##  7. 상신 후 상태 확인

---

상신이 완료된 문서는 기안 문서함에서 진행 상황을 실시간으로 확인할 수 있다.

🧭 전자결재 > 개인문서함 > `[기안 문서함]`

| 상태 표시 | 의미 |
| --- | --- |
| 진행 중 | 결재자 중 한 명 이상이 아직 결재하지 않은 상태 |
| 결재 완료 | 모든 결재자 승인 완료, 문서번호 채번됨 |
| 반려 | 결재자 중 한 명이 반려, 기안자에게 반환됨 |
| 임시저장 | 상신 전 임시저장된 상태 |

> 💡 결재 진행 상황은 문서 상세 화면의 결재선 영역에서 각 결재자의 처리 여부를 확인할 수 있다.

---

##  8. 정리

---

- 결재 상신 전 양식 설정을 꼭 확인하자. 양식에 따라 결재선·공개여부·보존연한이 고정될 수 있다.
- 문서정보의 `긴급 문서` 체크는 결재자 목록 최상단에 표시되므로, 급한 결재 시 활용하자.
- 결재선은 결재자·합의자·수신자·참조자·열람자로 구성되며, 각 역할의 열람 시점과 권한이 다르다.
- 자주 쓰는 양식과 결재선은 미리 저장해두면 반복 작업을 줄일 수 있다.
- 합의자가 2명 이상이면 순차합의 vs 병렬합의를 상황에 맞게 선택하자.
